# DevOps · Resumo Prova 2

Página de estudo (HTML + CSS + JS puros) resumindo as Aulas 16 a 33 da disciplina **DevOps Tools** — CI/CD, pipelines, GitHub Actions/GitLab CI, Docker no pipeline, Registry, releases e rollback, Cloud, Terraform e observabilidade.

## Conteúdo

- **Aula 16** — Fundamentos de CI/CD (CI × Delivery × Deployment)
- **Aula 17** — GitHub Actions & GitLab CI (workflow, evento, job, stage, runner)
- **Aula 21** — Docker no CI/CD (build × run, Dockerfile, pipeline)
- **Aulas 22–23** — Registry, versionamento semântico, releases e rollback
- **Aula 25** — Cloud: IaaS/PaaS/SaaS, regiões, AZs, computação e redes
- **Aula 27** — IaC & Terraform: blocos, ciclo de vida, state e comparação com Ansible
- **Aulas 31–33** — Observabilidade, Prometheus e Grafana (bônus, conteúdo pós-prova)
- **Cola da prova** + **quiz de 18 questões** com explicações

## Recursos

- Progresso de estudo salvo no `localStorage`
- Tema claro/escuro persistente
- Quiz interativo com feedback imediato
- Layout responsivo e estilos de impressão
- Imagens extraídas dos slides das aulas (Aula 27 e Aula 32)
